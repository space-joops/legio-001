# 레지오 마리애 주간 활동 보고

레지오 마리애 단원이 한 주간(주회~주회) 동안의 개인 기도 활동(평일미사참례, 사제를 위한 기도, 주모경, 묵주기도, 화살기도)을 큰 버튼으로 기록하고, 회차 단위로 주간 활동 보고를 만들어 공유할 수 있는 PWA입니다. 한국어/영어를 지원하며, 데이터는 기기의 로컬 스토리지에만 저장됩니다.

## 시작하기

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) 에서 확인할 수 있습니다.

## 빌드

```bash
npm run build
```

`output: 'export'` 설정에 따라 `out/` 디렉터리에 정적 사이트가 생성됩니다. 아무 정적 파일 서버로 배포하면 됩니다.

```bash
npx serve out
```

배포 도메인이 정해지면 소셜 공유 미리보기(OG 이미지) 절대경로가 올바르게 계산되도록 `NEXT_PUBLIC_SITE_URL` 환경변수를 배포 도메인으로 설정해 주세요 (예: `https://legio.example.com`).

## 주요 기능

- 회차/주회 일시 기반 주간 활동 기록, 탭 카운터 + 직접 숫자 입력
- 지난 주간 보고 기록 열람 및 공유(Web Share API, 미지원 브라우저는 클립보드 복사)
- 한국어/영어 전환
- PWA 설치(홈 화면 추가) 및 오프라인 앱 셸 지원
- 설정에서 데이터 내보내기(JSON) / 초기화

## 향후 계획

- 여러 단원의 제출본을 PR 단위로 취합하는 관리자 기능(현재는 로컬 스토리지 기반 개인용 앱). 내보내기 JSON 형식이 이 작업을 염두에 두고 설계되어 있습니다.

## 코드 지도 (Code Map)

프로젝트의 주요 디렉터리 및 파일 구조는 다음과 같습니다.

- **`src/`**: 애플리케이션의 주요 소스 코드가 위치한 디렉터리입니다.
  - **`app/`**: Next.js App Router 기반의 페이지 및 라우팅 구조를 정의합니다. (`history`, `report`, `schedule`, `secretary`, `settings` 등 주요 페이지 포함)
  - **`components/`**: 애플리케이션 전반에서 사용되는 재사용 가능한 React UI 컴포넌트들입니다. (버튼, 다이얼로그 등) CSS 모듈을 함께 사용합니다.
  - **`hooks/`**: 커스텀 React 훅 모음으로 로컬 스토리지 데이터 접근, 일정 관리 등 상태 관리 로직을 담당합니다.
  - **`i18n/`**: 다국어(한국어/영어) 지원을 위한 번역 사전 및 관련 로직을 제공합니다.
  - **`lib/`**: 로컬 스토리지 인터페이스, 데이터 변환, 유틸리티 함수, 타입 정의 및 상수들이 모여 있습니다.
- **`public/`**: 앱 아이콘, 웹 앱 매니페스트 등 정적 리소스와 PWA를 위한 서비스 워커(`sw.js`) 파일이 위치합니다.
- **`scripts/`**: 빌드 시 실행되는 스크립트로, PWA 프리캐시 매니페스트 목록을 생성하는 등의 작업을 수행합니다.
- **설정 파일**:
  - `package.json`, `next.config.ts` 등: 프로젝트 의존성 및 Next.js 빌드 설정(`output: "export"`)이 정의되어 있습니다.
