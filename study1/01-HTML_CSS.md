# 🎨 1. HTML과 CSS로 화면 예쁘게 꾸미기

웹 개발에서 **HTML**은 화면의 "뼈대(구조)"를 잡고, **CSS**는 그 뼈대에 "옷(디자인)"을 입히는 역할을 합니다.
이 프로젝트에서는 `CSS Modules`이라는 방식을 사용합니다. 파일 이름이 `.module.css`로 끝나는 파일들이 바로 그것인데요, 이렇게 하면 다른 파일의 CSS와 이름이 겹쳐서 디자인이 망가지는 것을 막아줍니다!

---

## 📌 1. 요소들을 화면 아래에 착! 고정하기 (하단 메뉴)

앱을 보면 화면 맨 아래에 항상 떠 있는 메뉴(BottomNav)가 있습니다. 스크롤을 내려도 항상 그 자리에 있죠? 어떻게 한 걸까요?
`src/components/BottomNav.module.css` 파일을 살펴봅시다.

```css
.nav {
  position: fixed; /* 💡 화면에 고정하겠다는 뜻입니다! */
  left: 0;         /* 왼쪽 끝에 착 붙이고 */
  right: 0;        /* 오른쪽 끝에도 착 붙여서 화면 전체 너비를 차지하게 해요 */
  bottom: 0;       /* 화면 맨 아래(바닥)에 착 붙입니다 */

  display: flex;   /* 안에 있는 메뉴 아이템들을 가로로 나란히 배치하기 위해 사용해요 */
  background: var(--color-surface); /* 배경색 지정 */
  z-index: 20;     /* 다른 요소들보다 위에 떠 있도록 층(계층)을 높여줍니다 */
}
```

**👨‍💻 직접 수정해보기:**
- `bottom: 0;` 을 `top: 0;` 으로 바꾸면 메뉴가 화면 위쪽으로 이동할까요? 한번 시도해보세요!

---

## 📌 2. 여백(간격) 조정하기: flex와 gap, padding

메뉴 안의 버튼들, 혹은 글자들 사이의 간격은 어떻게 띄울까요?
동일한 파일(`BottomNav.module.css`)의 `.item` 클래스를 봅니다.

```css
.item {
  flex: 1;           /* 여러 개의 아이템이 있을 때 넓이를 똑같이 1:1:1로 나누어가져요 */
  display: flex;     /* 이 아이템 안의 내용물(아이콘, 글자)도 배치해야 하니까 flex 사용 */
  flex-direction: column; /* 가로가 아니라 세로(위아래)로 배치해요 (아이콘 아래 글자) */
  align-items: center;    /* 가운데 정렬! */
  justify-content: center;/* 이것도 가운데 정렬! */

  gap: 2px;          /* 💡 아이콘과 글자 사이의 틈(간격)을 2px만큼 띄워줍니다 */
  padding: var(--space-1) 4px; /* 💡 상하좌우에 푹신한 쿠션(여백)을 줍니다 */
}
```

- **`gap`**: 요소들 사이사이의 간격만 벌려줍니다.
- **`padding`**: 요소 안쪽 테두리에 솜을 넣듯 쿠션을 주어 넓게 만듭니다. 반대로 바깥쪽을 띄울 때는 `margin`을 씁니다.
- **`var(--space-1)`**: 이건 미리 정의해둔 변수(variable)입니다. 일관된 간격을 주기 위해 숫자를 직접 쓰지 않고 변수를 가져다 쓴 거예요.

**👨‍💻 직접 수정해보기:**
- `gap: 2px;`를 `gap: 10px;`로 바꾸고 새로고침 해보세요. 아이콘과 글자 사이가 훅 벌어지는 걸 볼 수 있습니다!

## 📌 3. 시선을 사로잡는 마법, CSS 애니메이션!

앱을 처음 켤 때 스플래시 화면(시작 화면)이 부드럽게 나타나죠?
이것은 CSS 애니메이션 덕분입니다. `src/components/SplashOverlay.module.css` 파일을 확인해봅시다.

먼저 어떤 애니메이션을 만들지 정의합니다(`@keyframes`).
```css
/* 서서히 나타나는 애니메이션 정의 */
@keyframes fadeIn {
  from { opacity: 0; } /* 처음엔 투명도 0 (완전 투명해서 안 보임) */
  to { opacity: 1; }   /* 끝날 땐 투명도 1 (완전 선명하게 다 보임) */
}

/* 약간 아래에서 위로 살짝 떠오르며 나타나는 효과 */
@keyframes riseIn {
  from {
    opacity: 0;
    transform: scale(0.97); /* 원래 크기보다 아주 살짝 작게 시작 */
  }
  to {
    opacity: 1;
    transform: scale(1);    /* 원래 크기로 돌아옴 */
  }
}
```

그 다음, 정의한 애니메이션을 원하는 곳에 적용합니다.
```css
.image {
  /* ... 다른 스타일들 ... */

  /* 💡 riseIn 애니메이션을 400밀리초(0.4초) 동안 부드럽게(ease-out) 실행해라! */
  animation: riseIn 400ms ease-out both;
}
```

**👨‍💻 직접 수정해보기:**
- `400ms`를 `2000ms` (2초)로 바꾸면 앱을 켤 때 이미지가 아~주 천천히 나타납니다.
- 재미로 `riseIn` 대신 `fadeIn`으로 단어를 바꿔보세요. 나타나는 느낌이 어떻게 다른가요?
