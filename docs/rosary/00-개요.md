## 3. 사용자 입장에서의 흐름

1. 홈 화면 묵주기도 카드에 큰 숫자와 **구슬 5알**이 보인다
2. 숫자를 탭하면 구슬이 하나씩 채워진다. **5번째 탭에서 숫자가 +5** 되고 구슬이 비워진다
3. 카드의 **[기도문 보기]** 를 누르면 창이 뜬다
4. 창 맨 위에 **오늘 요일에 맞는 신비**의 안내가 나온다 (77장 중 1번째)
5. 화살표 버튼이나 **좌우 스와이프**로 넘긴다
6. 신비 선포 화면(6·20·34·48·62번째)에는 **성화**가 있다. 누르면 크게 보이고 묵상이 나온다
7. 77번째까지 가서 다음을 누르면 **"5단을 기록할까요?"**
8. [기록하기] → 숫자가 +5 되고 처음 화면으로 돌아간다

## 4. 5분 실습 — 지금 바로 손대 보기

```bash
npm install
npm run dev     # http://localhost:3000
```

### 실습 1. 오늘의 신비를 바꿔 보기

`src/lib/rosaryMysteries.ts` 의 `MYSTERY_BY_WEEKDAY` 에서 오늘 요일 자리를 다른 신비로 바꿔 보세요. 저장하면 화면이 바로 바뀝니다.

```ts
const MYSTERY_BY_WEEKDAY: MysteryId[] = [
  "glorious",  // 일요일  ← 여기를 "luminous" 로 바꿔 보세요
  "joyful",    // 월요일
  ...
];
```

### 실습 2. 스와이프를 더 둔감하게

`src/hooks/useSwipe.ts` 의 상수 하나만 바꾸면 됩니다.

```ts
export const SWIPE_THRESHOLD_PX = 50;   // → 150 으로 바꾸면 훨씬 세게 밀어야 넘어감
```

### 실습 3. 성모송 횟수 줄여서 빨리 끝내 보기

`src/lib/rosaryMysteries.ts` 에서 `HAIL_MARYS_PER_DECADE = 10` 을 `2` 로 바꾸면 전체가 **77장 → 37장**으로 줄어 끝까지 넘겨 보기 쉬워집니다. 테스트가 끝나면 꼭 되돌리세요.

> 확인 요령: 크롬 개발자 도구(F12) → **Application → Local Storage** 에서
> `legioMariae.currentReport` 를 열어 두면, 탭할 때마다 `counts.rosaryDecades` 와
> `rosarySetProgress` 가 어떻게 바뀌는지 눈으로 볼 수 있습니다.

## 6. 자주 하는 질문

**Q. 신비를 직접 고를 수는 없나요?**
지금은 없습니다. 요일로만 정해집니다. 만드는 방법은 [05-연습문제](05-연습문제.md) 고급 11번에 정답 코드까지 있습니다.

**Q. 영어로 바꾸면 성화를 눌러도 아무 일이 없어요.**
묵상 문장이 한국어만 있기 때문입니다. 자세한 이유는 [01-데이터](01-데이터.md) §6, 해결은 연습문제 고급 13번.

**Q. 창을 닫았다 다시 열면 처음부터인가요?**
아닙니다. 구슬을 채워 둔 만큼 건너뜁니다. 3알을 채웠다면 4단 신비 선포 화면부터 시작합니다. ([02-화면과-스와이프](02-화면과-스와이프.md) §4)

**Q. 성화 이미지를 바꾸려면?**
`public/images/rosary/` 에 `{신비}-{단}.jpeg` 규칙으로 넣으면 됩니다. 예: `joyful-1.jpeg`. ([01-데이터](01-데이터.md) §7)
